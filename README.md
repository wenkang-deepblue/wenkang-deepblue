# Hi, I'm Wenkang 👋

I build tools for creating, designing, and getting things done — from browser extensions and desktop apps to AI filmmaking, translation, and developer tools.

My projects explore a few recurring ideas: making creative work more accessible, giving people more control over their tools, and turning repetitive tasks into simpler workflows.

### Products you can try

- **🎨 [Color-Card](https://chromewebstore.google.com/detail/color-card/ggnlibimkfodncglaonodelcplopfcnc)** — A color toolkit for designers, developers, and presentation makers. Browse and copy colors, build custom palettes, and explore color harmonies. Pro adds palette generation from seed colors and images, plus Material-style theme roles. **Available on Chrome · Free + Pro.** [Website](https://color-card.deepblues.app) · [Legacy open-source version](https://github.com/wenkang-deepblue/Color-Card)

- **🔎 [FrontCap](https://chromewebstore.google.com/detail/frontcap/olebkldflhmagcjdeofhiljnleabglcc)** — Turn a real webpage into useful context for your coding assistant. Select UI elements, add annotations, and export Markdown with DOM, computed styles, source hints, and optional screenshots. Captured page content stays local. **Available on Chrome · Trial + paid plans.** [Website](https://frontcap.net)

### Open-source tools

- **🌐 [TransLay](https://github.com/wenkang-deepblue/TransLay)** — Translate Google Slides while preserving the presentation's layout, rich text, tables, and speaker notes. Uses deck-wide context for consistent terminology and adjusts text to fit the original design. **Self-hosted · Google Slides support.** Originally developed as a private product; now available as an open-source project.

- **🧠 [Ternion](https://github.com/wenkang-deepblue/Ternion)** — Bring three AI perspectives to a difficult engineering problem. A local gateway for Cursor and compatible clients that gathers code evidence, runs independent model analyses, and synthesizes a structured report, with optional implementation and review. **Open source · Run locally.**

- **🎛️ [frontend-design](https://github.com/wenkang-deepblue/frontend-design)** — A visual feedback loop for Claude Code and Codex. Explore a standalone HTML preview, adjust design choices, annotate individual elements, and export your decisions as an actionable Markdown prompt. **Open-source skill · No build step.**

- **🌈 [PyMCUlib](https://github.com/wenkang-deepblue/PyMCUlib-Pythonized-material-color-utilities)** — A Python port of Google's Material Color Utilities, covering perceptual color spaces, tonal palettes, image color extraction, contrast calculations, and dynamic themes. **Open-source Python library.**

- **🔌 [Cursor Gateway for Vertex AI](https://github.com/wenkang-deepblue/cursor-gateway-vertex-ai)** — Connect Cursor to Gemini through your own Google Cloud Vertex AI account. Handles authentication, model aliases, streaming, and OpenAI-compatible requests. **Open source · Self-hosted gateway.**

- **🛑 [GCP Billing Hardstop](https://github.com/wenkang-deepblue/gcp-billing-hardstop)** — Turn Google Cloud budget notifications into an automated billing shutoff, with message validation, budget filtering, and a simulation mode. **Open source · Cloud utility.** Notification delays mean it is not an exact spending cap.

### What I'm building

- **🎬 Auteur** — An AI filmmaking workspace for short dramas and videos. Connects production bibles, character references, scripts, storyboards, voice direction, and episode production through reviewable workflows. The focus is continuity across a production and control over each creative step. **In development · Private source.**

- **🧪 Enlivit** — An animation pipeline I'm building to turn a plain-language idea into a science explainer. Combines story planning, scientific review, visual production, and local English and Chinese narration, working toward a complete video workflow. **Early development · Private source, will open source very soon, no later than Nov, 2026.**

- **🔄 Unisynx** — A file synchronization and backup engine with peer-to-peer connections, encrypted cloud backups, and restore workflows. Designed as your last line of defense in the AI agent era: preserve recoverable versions of important files and code so an agent's unauthorized deletion doesn't mean permanent data loss. The goal is continuous backup, recovery whenever you need it, and synchronization across your devices. Current development focuses on the macOS engine, with the desktop interface still taking shape. **In development · Private source. The 1st version will be launched no later than Dec, 2026**

- **📸 BoxSnap** — A desktop screen capture tool (both static and dynamic screen) with region selection, scrolling capture, pixel magnification, and quick copy/save actions. Built around capturing exactly the part of the screen you need. **In development · Private source. The 1st version will be launched no later than Dec, 2026**
